# Commandes Git utilisées

## 1. Vérifier l'état du projet

```bash
git status
```

## 2. Ajouter le fichier index.html

```bash
git add index.html
```

## 3. Enregistrer les modifications

```bash
git commit -m "Ajout du titre principal dans index.html"
```

## 4. Vérifier l'état du projet

```bash
git status
```

## 5. Ajouter le fichier commandes.md

```bash
git add commandes.md
```

## 6. Enregistrer le fichier commandes.md

```bash
git commit -m "Ajout du fichier commandes.md"
```

## 7. Synchroniser avec GitHub

```bash
git push
```
