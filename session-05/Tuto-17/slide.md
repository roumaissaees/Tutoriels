## Synthèse de ma veille technologique

- **Définition en une phrase :** Un SGBDR comme MySQL est un système qui permet de stocker, organiser et gérer durablement des données dans des tables reliées entre elles.

- **Problème résolu pour le projet :** MySQL permet de conserver durablement les articles du Blog dans une base de données, contrairement aux données temporaires stockées en mémoire vive (RAM).

- **Mes 3 mots-clés :** SGBDR (MySQL) — Langage SQL — Extension PDO sécurisée.
